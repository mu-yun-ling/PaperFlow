# PaperFlow
本项目为南开大学软件学院 **企业级ai** 结课大作业项目。  
个人文献阅读与笔记管理系统，面向大学生与科研初学者。采用 React + Vite + TypeScript + Ant Design + ECharts、Flask + SQLAlchemy、SQLite，前后端通过 REST API 通信。

## Windows 本地运行

需要 Python 3.10+（本次使用 3.12）和 Node.js 22.13+（本次使用 24.11）。请在项目根目录打开 PowerShell。第六阶段新增 pypdf、pdfjs-dist、Markdown / KaTeX 等依赖：已有环境请先执行第 1 步更新依赖与数据库，再启动服务；本次开发环境已安装新增依赖。

### 1. 首次安装

```powershell
.\scripts\setup.ps1
```

默认 `python` 版本过旧时，指定较新解释器的真实路径：

```powershell
.\scripts\setup.ps1 -PythonExecutable 'C:\你的Python目录\python.exe'
```

脚本在项目内创建 `.venv`，按锁文件安装后端依赖，执行 `npm ci`，创建缺失的数据表并升级旧库。它不会清空已有数据库。升级或运行 `init-db` 前请停止后端并备份 `backend/instance`。此机器默认 `python` 是 3.8，`py` 列出的 3.14 路径已失效；本次使用本机提供的 Python 3.12 建立了虚拟环境，日常运行请使用脚本或 `.venv\Scripts\python.exe`。

如 PowerShell 执行策略阻止本项目脚本，可仅为本次进程放行，例如 `powershell -ExecutionPolicy Bypass -File .\scripts\start-backend.ps1`，无须更改系统策略。

### 2. 启动后端

```powershell
.\scripts\start-backend.ps1
```

后端地址：<http://127.0.0.1:5000>，健康检查：<http://127.0.0.1:5000/api/health>。

### 3. 新开一个 PowerShell 启动前端

```powershell
.\scripts\start-frontend.ps1
```

打开 <http://127.0.0.1:5173>。Vite 将 `/api` 代理至后端端口 5000，开发时无须额外配置 CORS。两个终端都保持运行；按 `Ctrl+C` 停止对应服务。如果端口被占用，先停止之前启动的同一服务。

## 页面使用

1. 在“标签管理”中创建标签，也可以先录入文献、稍后补充标签。
2. 在“文献库”点击“新增文献”，可先上传 PDF，等待识别标题、作者、年份、DOI 和摘要，再检查 / 补充后保存。只有标题必填，也支持不上传 PDF 直接录入。
3. 保存后进入详情；通过更多菜单的“编辑文献”修改信息和多标签关联，顶部可收藏。PDF 阅读状态随进度自动变化，无 PDF 时可在编辑页手动记录状态。
4. 在详情点击“开始阅读”或“继续阅读”，进入左侧 PDF、右侧笔记的阅读空间；原文右侧“···”菜单提供下载、替换和删除。选择“替换原文”进入编辑页选择新 PDF，确认保存后替换。
5. “我的阅读笔记”分为“在线笔记”和“笔记附件”两个页签。在线笔记支持 Markdown 编辑 / 预览 / 对照，内容不能为空；附件可上传多个 PDF / DOCX / MD / TXT，点“查看”预览，在更多菜单中下载或删除。
6. 删除标签仅移除关联；删除文献会同时删除论文 PDF、在线笔记及笔记附件，操作前均有确认提示。

### PDF 与笔记附件

- 单文件最大 25 MB，同时检查扩展名、MIME 和基本文件内容。文本笔记使用 UTF-8 编码；Markdown 默认渲染排版，可切换源码，嵌入 HTML 转义显示，不执行脚本。
- PDF 使用本地 pypdf 读取 metadata 和前两页文本，再结合规则识别。只填入空字段，允许修改；扫描件不做 OCR，加密 / 异常 PDF 或解析超时会提示手动补充，不影响保存原文件。启发式识别可能不准确，尤其是多栏标题、作者和年份，保存前请检查。
- 解析阶段不落盘、不建库；文件和文献信息在点击“保存文献”后一起提交。因此取消录入不会留下无归属文件。替换失败保留旧文件和原文献信息。
- PDF 使用随项目提供的 PDF.js 画布阅读器，支持页码、翻页、缩放与适合宽度；损坏或加密 PDF 显示失败提示并保留下载入口。DOCX 下载后使用 Word 或其他兼容阅读器打开。
- `npm run dev` / `npm run build` 会自动准备 PDF 字体、CMap 和解码资源，不依赖外部 CDN。阅读器按需加载。

### Markdown 写作与阅读

- `.md` 附件默认展示标题、粗体、列表、引用、代码块、表格、任务清单、删除线和链接；“源码”切换可核对原文，下载仍保留原文件。
- 新建 / 编辑在线笔记时选择“编辑”“预览”或“对照”。对照模式可边写边看效果，保存后列表显示排版结果；旧的纯文本笔记仍能正常阅读和编辑。
- 在线笔记与 `.md` 附件均支持 `$E=mc^2$` 行内公式，以及独立段落中的 `$$...$$` 块级公式；也支持 `\(...\)` / `\[...\]`。支持 KaTeX 的常见 LaTeX 数学语法（分式、根号、上下标、求和、积分、矩阵等），不是完整 TeX 文档编译器。
- 渲染使用 react-markdown + remark-gfm + remark-math + rehype-katex；字体打包在本地，无需 CDN。不启用原始 HTML 或可信 LaTeX 命令，危险 URL 被过滤；错误 / 不支持的公式保留可见提示，源码不变。TXT 保持纯文本，DOCX 下载后本地查看。
- 详情以原文进度、摘要和笔记为主，论文信息放在低对比度侧栏，创建时间折叠；最近笔记优先展示。窄屏改为单列；文献库其他条件通过“更多筛选”展开。

### 阅读进度与自动状态

- PDF 成功打开后记录总页数并恢复上次页码；仅打开、缩放、关闭或恢复位置不增加进度，也不更新最近阅读时间。
- 翻页 / 输入页码后回车跳转并成功渲染、主动向下滚动到页底，会记录当前页与最近阅读时间。单页或不需要滚动的文档也可点“本页已读”。缩放、窗口大小变化引起的滚动不计为阅读。
- 历史最远页码只增不减；百分比按最远页码 / 总页数计算，未触发阅读为 0%，非末页限制为 1%～99%，到达末页为 100%。它表示阅读到的位置，不证明每一页已逐字阅读。
- 0% 自动为“未开始”，1%～99% 为“阅读中”，100% 为“已读完”。已读完状态不会因回看、手动编辑或替换 PDF 而回退。替换文件后的页码与进度从新文件重新记录。
- 阅读空间右侧分为“上传笔记”和“在线笔记”：有附件时默认打开上传笔记，通过下拉框切换文件，MD（含 LaTeX）、PDF、TXT 可直接与原文并排阅读，DOCX 保留下载后本地打开。在线笔记仍支持查看、新建与编辑。
- 桌面端拖动中间带圆点的分隔条调整笔记宽度，自动记住比例；双击恢复默认宽度，也可聚焦后用左右方向键调整。两侧独立滚动，调整宽度或切换笔记不改变论文页码与阅读进度；窄屏自动上下排列。
- 进度保存失败会明确提示并提供重试，未同步时关闭需选择放弃；刷新或关闭标签页会提示尚未保存。
- 若 PDF 不能显示，先确认前后端仍在运行。页面组件加载失败会提供重新加载入口；PDF 加载 / 单页渲染超过 30 秒会停止等待并提供“重试预览”。阅读空间始终提供“下载原文”。密码保护和损坏文件会单独提示。

### 阅读概览

- 点击导航“阅读概览”，查看整个文献库的统计，不受文献列表筛选和分页影响。
- 状态环形图展示三种阅读状态，悬停查看数量与占比；年份柱状图按年份升序展示，空年份单独归入“未填写”。
- 新增、删除或修改阅读状态后，重新进入概览自动查询最新数据；窗口恢复焦点或页面重新可见时也会查询，可随时点击“刷新统计”。当前没有后台轮询或服务端推送。
- 加载时显示提示，空库显示四项零值和新增入口，接口失败显示错误及“重试”。

### 搜索、筛选和排序

- 在列表上方填写标题或作者关键词，进行字面子串搜索；`%`、`_`、`&` 等按普通字符处理。
- 标签和阅读状态从下拉框选择；年份填写整数；研究主题填写完整主题名称，按精确匹配查询。
- 多个条件同时满足才会出现在结果中。停止输入约 300 毫秒后自动查询，并回到第一页；翻页保留当前条件和排序。
- 可按年份、创建时间、更新时间升序或降序排列；默认创建时间降序。年份为空的文献在年份排序中始终置后。
- “清空筛选”会清除全部条件、恢复默认排序并回到第一页。无结果时可调整条件或清空筛选。
- 非法年份会显示校验提示，列表保留上次有效结果；修正年份后恢复自动查询。条件仅保存在当前列表页面，离开页面或刷新浏览器后恢复默认值。

## 配置和数据

- 默认 SQLite 文件：`backend/instance/paperflow.db`，首次运行后端脚本时创建。
- AI 可直接在网站顶部“AI 设置”中接入，无需编辑 `.env`。如需配置数据库或提供 AI 初始值，可将 `backend/.env.example` 复制为 `backend/.env`；环境变量优先于 `.env`，网页保存的 AI 设置优先于这两者。
- `sqlite:///paperflow.db` 是相对于 Flask instance 目录的路径。Windows 绝对路径示例：`sqlite:///D:/data/paperflow.db`，其父目录需要已存在。
- `.env`、数据库、上传目录与虚拟环境均已加入 `.gitignore`。
- 默认上传目录：`backend/instance/uploads/`。数据库仅保存 UUID 相对路径和原始文件名，文件必须绑定具体文献；不要单独移动上传文件。
- 备份：停止后端服务后同时复制数据库与 uploads 目录（推荐备份整个 `backend/instance`）；恢复时同时还原，保持文件和记录一致。
- `init-db` 以幂等方式迁移旧 SQLite 库：移除作者非空 CHECK，保留文献 ID、索引、标签和笔记，新增附件表与阅读进度表。已有第六阶段数据库也须执行以补建进度表；启动脚本会先执行该命令，不得通过删除数据库升级。
- 文件替换 / 删除先移到隔离目录，数据库失败时恢复；提交后清理。文件占用导致清理失败会记录日志，下一次 `init-db` 重试；异常退出后该命令也会恢复仍被引用的隔离文件并清除无引用 UUID 文件。因此只应在后端停止时执行初始化 / 升级。
- 当前面向本机个人使用，默认监听 `127.0.0.1`，无用户系统。
- 独立联调时可在启动 Vite 前设置 `PAPERFLOW_API_TARGET`，例如 `http://127.0.0.1:5001`；未设置时仍代理至 5000。该变量只配置开发代理。

## API 操作示例

以下命令在后端启动后执行，会创建示例文献与笔记；再次执行同一标题会返回 409 重复提示。

```powershell
$apiBase = 'http://127.0.0.1:5000/api'
$paperBody = @{
    title = '我的第一篇文献'
    authors = '张三; 李四'
    year = 2024
    research_topic = '自然语言处理'
    reading_status = 'reading'
} | ConvertTo-Json
$paperResult = Invoke-RestMethod -Uri "$apiBase/papers" -Method Post `
    -ContentType 'application/json; charset=utf-8' -Body ([Text.Encoding]::UTF8.GetBytes($paperBody))
$paperId = $paperResult.data.id

$noteBody = @{ content = '阅读后记录：研究问题、方法、结论和局限。' } | ConvertTo-Json
Invoke-RestMethod -Uri "$apiBase/papers/$paperId/notes" -Method Post `
    -ContentType 'application/json; charset=utf-8' -Body ([Text.Encoding]::UTF8.GetBytes($noteBody))

Invoke-RestMethod -Uri "$apiBase/papers/$paperId"
Invoke-RestMethod -Uri "$apiBase/dashboard"
```

完整字段、过滤参数与接口列表见 [设计文档](docs/design.md)。API 的阅读状态值为 `not_started`（未开始）、`reading`（阅读中）、`completed`（已读完）。

## 第七阶段 AI 配置与接口

推荐直接在网页操作，无需编辑配置文件或重启服务：

1. 打开网站，点击侧栏 **AI 设置**（文献详情的 AI 区域也有入口）。
2. 填写服务商的 **API 基础地址、模型名称、API Key**，打开“启用 AI”。
3. 点击 **测试连接**。测试使用当前表单，不发送论文或笔记，也不会保存设置，可能消耗少量模型额度。
4. 点击 **保存设置**，返回文献详情使用 AI。保存立即生效，重启后保留。

后续修改其他选项时密钥留空即可保留。更换服务地址时须重新填写对应密钥；勾选“清除已保存的密钥，同时关闭 AI”后保存即可清除。高级设置提供超时、输出上限和 token 参数。

网页设置保存在后端 `backend/instance/ai-settings.json`，不会回传密钥，也不进入 Git。该文件包含明文密钥，只适用于当前本机单用户运行方式，不要分享或同步整个 `instance` 目录。设置接口限制本机来源，并检查写入请求头与跨站来源；项目仍未实现账号和多用户权限，不应直接公开部署。

如果偏好环境变量，也可以在**尚未通过网页保存设置时**使用以下初始配置；已有 `.env` 请合并字段，保留数据库配置。网页设置一旦保存，将优先于环境变量与 `.env`。无需新增依赖或数据库迁移。

```dotenv
AI_ENABLED=true
AI_API_KEY=填写你的服务商密钥
AI_BASE_URL=https://api.openai.com/v1
AI_MODEL=填写账户可用的模型名称
AI_TIMEOUT_SECONDS=45
AI_MAX_OUTPUT_TOKENS=3000
AI_TOKEN_PARAMETER=max_completion_tokens
```

API 基础地址不包含 `/chat/completions`，后端会自动追加。其他兼容服务可替换地址与模型；若其仅支持 `max_tokens`，在高级设置中选择该参数。请求字段参考 [OpenAI Docs：Chat Completions](https://developers.openai.com/api/reference/resources/chat)。超时范围 1～60 秒，输出上限 256～8000 tokens。模型需要能在该预算内返回文本或 JSON；被截断、拒答、格式不完整的结果会提示重试。状态接口只检查本地配置，网页“测试连接”才会真实请求服务。关闭 AI 只需在网页关闭开关并保存。

| 接口 | 用途 |
| --- | --- |
| `GET /api/ai/status` | 本地配置可用状态，不返回密钥 |
| `GET /api/ai/settings` | 读取设置和密钥是否已配置，不返回密钥 |
| `PUT /api/ai/settings` | 验证并持久化设置，立即生效 |
| `POST /api/ai/settings/test` | 测试当前表单配置，不保存、不发送论文与笔记 |
| `POST /api/papers/:id/ai/analysis` | 六项论文分析，返回 `markdown` 与 `source` |
| `POST /api/papers/:id/ai/keywords` | 返回 3～8 个候选 `keywords` 与 `source` |
| `POST /api/papers/:id/ai/reading-summary` | 结合在线笔记，返回 `markdown` 与 `source` |
| `POST /api/papers/:id/ai/keywords/apply` | 提交 `{"keywords":["所选词"]}`，原子合并标签并返回文献详情 |

生成接口不修改数据。阅读总结保存复用 `POST /api/papers/:id/notes`，新增一条笔记；不会覆盖原摘要、标签或已有笔记。页面内暂存 AI 结果，离开前可复制或保存总结。

输入包括论文标题、作者、年份、来源、DOI、研究主题、摘要（最多 6000 字符）和本地 PDF 文本。复用 pypdf 的独立进程解析，12 秒超时，最多均匀抽取 24 页及 24000 字符，附页码；无正文时使用摘要并提示范围，无正文且无摘要则拒绝生成。阅读总结额外使用最新 20 条在线笔记，共最多 8000 字符，暂不解析笔记附件。UI 会明确显示截取、摘要回退、无笔记等情况；字符上限不是精确 token 预算，小上下文模型仍可能需要调整配置。

AIService 负责配置、提示词、HTTP 调用、响应校验与错误映射；`ai_settings.py` 负责网页设置校验、原子持久化和公开字段过滤，`ai_context.py` 负责业务数据与输入边界，`routes/ai.py` 负责接口与确认写入。密钥仅在后端调用时使用，失败响应不回传上游原始错误；请求不自动重试，避免重复费用。生成时按钮禁用，切换文献会取消前端等待（上游已开始的调用不保证取消）。

网页设置补充后的验收：后端 **217 项**、前端 **40 项**测试通过，TypeScript 与生产构建通过；详细结果见[第七阶段验收记录](docs/phase-7-verification.md)。

## 第八阶段阅读工作台

参照概念设计图统一为暖白、浅绿与墨绿界面：侧栏导航、首页阅读概览、紧凑文献卡片，以及原文 / 对照 / 笔记三种阅读布局。文献库支持卡片和紧凑视图；对照和笔记模式分别记住分栏宽度。

PDF 支持页面缩略图、选中文字摘录、高亮和片段 AI 解释。点击“摘录到笔记”后，右侧打开带有原文与页码的草稿卡；填写章节、我的理解及标签后保存。AI 解释可以一键追加到“我的理解”，保留已有文字，保存后才生效。阅读器和详情页中的 `P.x / 查看原文` 均可返回对应 PDF 页。

多页 PDF 连续纵向排列，仅渲染视口附近页面；滚动同步当前页和缩略图高亮，输入页码或点击缩略图可定位。缩放及调整栏宽保持页内相对位置，同一浏览器重新打开时恢复页内位置（页码与阅读进度仍由后端保存）。阅读空间的笔记采用紧凑布局：页码和章节置顶、理解为主体、摘录最多三行可展开，编辑 / 删除收进更多菜单，标签与时间弱化。当前页笔记浅色高亮，左右独立滚动。

手动新建笔记默认也使用结构化卡片，页码和摘录均可为空。旧 Markdown 笔记保留原编辑方式；新卡片的摘录和理解支持 Markdown + LaTeX。无需修改旧数据库。首页已有统计内容，因此移除了重复的“阅读统计”导航。扫描件没有可选文字时不提供文本摘录，本阶段未加入 OCR。

新增 `POST /api/papers/:id/ai/explain`，接收 `file_id`、`page`、`text`，只将标题、页码和所选片段发送给已配置的 AI 服务。不会自动改写笔记。

验收结果、运行独立示例预览的方法与截图见 [第八阶段验收记录](docs/phase-8-verification.md)。后续开发范围以新的阶段要求为准。

### 书签笔记与 PDF 标记

在线笔记采用页码色签与理解摘要的书签样式，点击“展开笔记”显示完整理解、原文摘录与标签。点击页码或“查看原文”仍可定位原文，手动笔记和旧 Markdown 笔记继续兼容。

PDF 工具栏新增“选择 / 画笔 / 高亮 / 文字 / 橡皮”：画笔拖动画线并自动保存；高亮模式选中文字即保存选区；文字模式点击页面空白处输入批注，选择模式点击已有文字可编辑；橡皮点击新标记删除。支持四种颜色，标记坐标随页面缩放，重新打开会恢复。保存失败有提示，失败的画线保留并可重试。

标记存入新增的 `pdf_annotations` 表，按附件独立保存，删除附件时级联清理；不改动旧笔记字段。正常运行 `scripts/start-backend.ps1` 会通过现有幂等初始化补建表并保留旧数据。标记属于 PaperFlow 阅读层，目前“下载原文”下载原始 PDF，不含这些标记。
