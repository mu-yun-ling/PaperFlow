我要开发一个课程综合实践项目：

PaperFlow —— 文献阅读与笔记管理系统

这是一个供大学生和科研初学者使用的个人文献管理工具，我以后也会实际使用，所以请兼顾课程验收和实际体验。

技术栈：
前端：React + Vite + TypeScript + Ant Design + ECharts
后端：Python Flask + SQLAlchemy
数据库：SQLite
前后端分离，REST API。
项目需要能够在 Windows 本地运行。

核心功能：

1. 文献管理
支持文献新增、编辑、删除、查看。

文献字段至少包括：
- 标题
- 作者
- 年份
- 期刊/会议
- DOI
- 原文链接
- 摘要
- 研究主题
- 阅读状态
- 是否收藏

阅读状态：
- 未开始
- 阅读中
- 已读完

标题、作者不能为空。
DOI 或标题重复时应给出提示。

2. 标签管理
支持创建、删除标签，以及给文献添加/移除标签。
一篇文献可以有多个标签。

3. 阅读笔记
每篇文献可以创建多条笔记。
支持笔记新增、编辑、删除。
笔记必须和具体文献关联，禁止空笔记。

4. 搜索与筛选
支持：
- 标题搜索
- 作者搜索
- 标签筛选
- 年份筛选
- 阅读状态筛选
- 研究主题筛选
- 排序

5. 文献详情页
展示：
标题、作者、年份、期刊、DOI、链接、摘要、标签、阅读状态、收藏状态和阅读笔记。

6. Dashboard
展示：
- 文献总数
- 已读数量
- 阅读中数量
- 未开始数量
- 阅读状态统计图
- 年份/标签等统计图

所有统计数据必须来自数据库，不能写死。
修改文献状态后统计数据应同步变化。

7. 异常处理
处理：
空标题、空作者、非法年份、重复文献、重复 DOI、空笔记、不存在的数据、数据库异常等。

8. AI 扩展
第一版暂时不真正接入 AI，只预留 AIService。

以后计划增加：
- AI 生成论文摘要
- AI 提取关键词
- AI 根据论文和笔记生成阅读总结

API Key 必须通过环境变量配置。

第一版不要做：
- 登录注册
- 多用户权限
- RAG
- 向量数据库
- 知识图谱
- 微服务
- Redis
- Docker 集群

代码要求：
- 前后端结构清晰
- 后端拆分 models、routes、services
- 前端合理拆分页面和组件
- Python 核心代码写中文注释，关键部分要注释清楚，但是不要有ai的感觉
- 不要把所有代码堆进单个文件
- 界面简洁现代，类似个人知识管理工具，不要做成明显的课程作业网页

项目必须形成完整的数据闭环：
添加文献 → 标签分类 → 设置阅读状态 → 写笔记 → 搜索 → 查看统计。

现在先不要一次性生成全部代码。

第一步请先：
1. 设计数据库表
2. 设计主要 REST API
3. 给出开发顺序

然后开始实现第一阶段：
项目骨架 + 数据库 + 后端基础 API。

每完成一个阶段先运行和检查，再继续下一个阶段。
