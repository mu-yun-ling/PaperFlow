# PaperFlow 使用与配置

## 录入与管理

新增文献时只有标题必填。可以先选择 PDF，等待本地识别标题、作者、年份、DOI 和摘要，再检查并保存；解析只预填空字段。识别失败可以手动填写，扫描 PDF 不提供 OCR。

文献库支持标题、作者、标签、年份、阅读状态、研究主题和收藏筛选，以及排序、分页、卡片与紧凑视图。研究主题按完整名称匹配。进入详情后返回会保留查询条件和位置；点击首页标签可直接查看对应文献。

删除文献会同时删除它的 PDF、笔记与附件。删除标签仅解除关联。

## 阅读与摘录

点击“开始阅读／继续阅读”进入工作台。原文连续纵向滚动，支持页码输入后按回车、缩略图跳转、缩放及阅读位置恢复。

“专注原文／对照阅读／专注笔记”控制阅读空间的分配，不切换右侧内容。桌面可拖动中间分隔条调整宽度，双击恢复默认值；也可聚焦分隔条后按方向键。

选中 PDF 文字后可摘录、调用 AI 解释或高亮。已有草稿时，“加入当前笔记”继续追加；选择“另建笔记”会保留原草稿。多段摘录各自保存页码，点击来源能返回具体段落并短暂强调。扫描件没有文字层时不能拖选摘录，可以手动记录页码。

阅读位置与历史最远阅读页分别保存。进度表示到达的位置，不表示逐页精读；已完成的状态不会因回看而降低。替换 PDF 后重新记录新文件的进度，旧摘录仍保留，但需要重新关联原文。

## 在线笔记与草稿

在阅读器内新建笔记默认关联当前页，可以修改页码或选择“全文笔记”。详情页也可指定页码。“我的理解”和摘录都支持 Markdown 与 LaTeX，例如 `$E=mc^2$`、`$$\sum_i x_i$$`。

笔记可收录多段、跨页原文；移除一段摘录不会删除理解。笔记列表支持搜索、当前页筛选和页序排列。旧 Markdown 笔记及旧章节信息继续保留。

编辑内容即时保存为当前浏览器的本机草稿。详情页与工作台共享草稿；刷新后从“本机草稿”恢复。可收起、切换或另建草稿，点击“保存笔记”才提交数据库。清理浏览器数据会清除尚未正式保存的草稿；浏览器存储不可用时页面会明确提示。

## PDF 批注

- 画笔拖动画线，高亮模式选中文字后保存；也可以在普通选区菜单中高亮。
- 文字模式点击页面添加批注；选择模式单击已有批注选中，拖动上方把手移动，拖动右下角调整文本框，双击或点“编辑”修改文字。
- 已选标记可以改色或删除；文字还可以改字号，方向键微调位置，Shift 加方向键扩大步幅。
- 工具栏可撤销／重做本次打开期间的操作；聚焦 PDF 后也可用 Ctrl+Z、Ctrl+Shift+Z。输入文字时保留编辑器本身的撤销操作。
- 批注保存在 PaperFlow 阅读层，不修改原 PDF；“下载原文”不包含这些批注。

## 笔记附件

支持 PDF、DOCX、MD、TXT，单文件不超过 25 MB。可在详情或阅读器的“笔记附件”上传；PDF、Markdown 和 TXT 支持在线对照，DOCX 下载后用本地应用打开。Markdown 支持表格、列表、代码、链接及 LaTeX 数学公式，不执行嵌入 HTML。

## AI 设置

在侧栏“AI 设置”填写服务地址、模型名称和 API Key，启用后测试连接并保存。地址不包含 `/chat/completions`，例如兼容服务的 API 根地址。高级设置可调整超时、输出上限及 token 参数。配置保存后立即生效。

生成分析会使用文献信息、摘要和本地提取的正文片段；阅读总结还会使用在线笔记。片段解释只发送所选内容及相关文献信息。页面会显示来源范围与失败提示，生成结果需自行核对；加入笔记后仍可编辑，保存前不会覆盖已有内容。

设置文件为 `backend/instance/ai-settings.json`，包含明文密钥，不应分享或提交。密钥留空可保留已有值，更换服务地址时需要重新填写密钥。没有网页设置时，可通过 `backend/.env` 配置；字段与接口说明见[AI 阶段记录](phase-7-verification.md)。

## 安装、数据与排错

- Windows 上先运行 `scripts/setup.ps1`，然后在两个终端分别启动前后端。若默认 Python 过旧，使用 `scripts/setup.ps1 -PythonExecutable 'Python解释器的完整路径'`。
- 默认前端端口 5173，后端端口 5000；开发代理可用 `PAPERFLOW_API_TARGET` 指向其他本地后端。
- 默认数据库为 `backend/instance/paperflow.db`，文件在 `backend/instance/uploads/`。备份前停止后端，并同时保留数据库与文件目录。
- 启动后端时会保留原数据并执行幂等升级。不要通过删除数据库升级，也不要在后端运行中单独移动附件文件。
- PDF 字体与解析资源随项目本地准备。预览失败时可重试或下载；密码保护文件需用本地阅读器打开。
- 仅供本机个人使用，默认监听 `127.0.0.1`，没有账号与多用户权限。

## 开发检查

在 `backend` 运行 `..\.venv\Scripts\python.exe -m pytest -q`；在 `frontend` 运行 `npm.cmd test` 和 `npm.cmd run build`。测试使用独立数据库及上传目录。

更多实现、边界和各阶段验证见[开发与验收记录](development.md)。
