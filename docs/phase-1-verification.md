## 自动化测试覆盖

- 新增文献→分类→修改阅读状态→新增/编辑笔记→组合搜索→查看详情→统计变化→删除的 API 闭环。
- 标题、作者必填；非法 JSON 类型、未知字段、错误年份、阅读状态、收藏类型、DOI 和 URL 校验。
- 标题 Unicode、大小写与空白标准化去重，DOI URL 前缀与大小写标准化去重，多条空 DOI。
- 多标签关联去重、幂等添加和移除、删除标签保留文献。
- 非空笔记、长度限制、禁止修改笔记归属，笔记更新和删除。
- 搜索的 SQL 通配符字面处理、组合筛选、分页、排序及空年份处理。
- 不存在资源、错误筛选、错误请求方法、Content-Type 和请求体大小限制。
- 数据库故障与约束冲突返回 JSON，回滚后原数据保持不变，不向客户端泄漏内部错误。
- SQLite 外键开启、孤立笔记和重复标题被数据库拒绝；文献删除清理笔记与关联。
- 关闭数据库连接后新建应用仍能读取原数据；重复初始化不清空数据库。
- AIService 各入口明确返回未实现，不发起 AI 请求。

测试使用独立临时数据库，个人文献库保持空白。
